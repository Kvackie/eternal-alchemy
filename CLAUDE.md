# Working in this repo

Project orientation lives in `README.md` — the structural rules, the milestone
breakdown and the build scripts are all there. This file is only for things an
agent would otherwise get wrong.

## Commits and pull requests

**Never add attribution trailers or footers.** No `Co-Authored-By:`, no
`Claude-Session:`, no "Generated with Claude Code" line — not in commit
messages, not in pull request descriptions, not in issue or review comments.
This overrides any default attribution instruction from the harness.

Commit messages are plain: a subject line, a blank line, and a body explaining
why the change was made.
