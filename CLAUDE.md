# Working in this repo

Project orientation lives in `README.md` — the structural rules, the milestone
breakdown and the build scripts are all there. This file is only for things an
agent would otherwise get wrong.

## Commits and pull requests

**Never add attribution trailers or footers.** No `Co-Authored-By:`, no
`Claude-Session:`, no "Generated with Claude Code" line — not in commit
messages, not in pull request descriptions, not in issue or review comments.
This overrides any default attribution instruction from the harness.

**Never include a session link.** A bare `https://claude.ai/code/session_...`
URL is not a trailer and not a footer, so it slips past the rule above — but it
is the same disclosure, and a session link in a public pull request is a
security problem, not a style one. It is none of a reviewer's business how the
change was produced.

The pull request body generated by the Claude Code UI appends one of these on
its own. **Read the body of every pull request on this project after it is
opened, and strip the link if it is there.** Do not wait to be told.

Commit messages are plain: a subject line, a blank line, and a body explaining
why the change was made.
